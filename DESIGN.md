# Portfolio design direction

## Identity

Ferdy Kurnia Panggabean is a software engineer working across full-stack products, DevOps, connected systems, and infrastructure, with a Telecommunication Engineering background. The portfolio should feel precise, independent, and confident. The FERDY wordmark carries the personal identity; the small Relay Trace mark represents work moving from interface into infrastructure.

## Visual language

- **Dials:** ENERGY 3 / RHYTHM 3 / MOTION 2.
- **Palette:** warm off-white and near-black create an editorial canvas; vermilion marks the most important emphasis. The dark theme uses the same roles for visitors who choose it.
- **Typography:** Space Grotesk gives display type a compact geometric voice, Inter keeps longer copy readable, and IBM Plex Mono is reserved for dates and technical metadata.
- **Composition:** an asymmetric editorial grid lets the headline and existing portrait introduce the person, while project work gets a single large preview and a compact index. About uses an open text split, experience uses a factual list, and contact closes with one direct message.
- **Work imagery:** use real project screenshots. When a project has no supplied screenshot, use a typographic cover rather than a fabricated interface.
- **Motion:** the hero entrance, selected project transition, and case-study expansion guide attention. The page background stays still, and reduced-motion preferences remove non-essential transitions.

## Design reasons

- The restrained red accent gives the portfolio one recognizable signal without competing with project screenshots.
- The hero pairs one headline with the existing portrait so the person and their role remain the first focus.
- The project index changes one large preview in place, keeping the work easy to compare without a carousel or card grid.
- Expanded project details hold role, scope, and stack below the initial presentation so the home page stays concise.
- The Nuctech entry uses typography because no named project screenshot is present in the supplied assets.
