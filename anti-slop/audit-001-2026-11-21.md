# Antislop audit 001

Date: 2026-11-21  
Mode: after  
Scope: all application UI, copy, responsive styles, accessibility, and code comments under `src/app`, plus the hero image used by the UI.

## Findings

1. **HIGH — R-23: AI-generated portrait is presented as a real profile photo.** `src/app/layout/Home.js:90-95` uses `public/assets/profile_ai.jpg` with alt text naming Ferdy. The asset is a photorealistic generated portrait and is not identified as an illustration, so visitors can read it as an authentic likeness.

2. **HIGH — R-25: Accent text fails contrast in light theme.** `src/app/globals.css:59-68` sets `--accent: #f13a24` on `--bg: #f2f1ec`; the calculated contrast is **3.46:1**, below 4.5:1 for normal text. The accent appears on small labels and links, including project and contact content.

3. **HIGH — R-27: Blog API failures are reported as an empty publication list.** `src/app/blog/page.js:10-20,55-58` converts network and HTTP failures to `[]`, then displays “No notes published yet.” This tells visitors no posts exist when the service may simply be unavailable; there is no distinct error state.

4. **HIGH — R-32: The mobile navigation and project overlay do not manage keyboard focus.** `src/app/components/Navbar.js:183-237` does not close the mobile panel on Escape or keep focus within it. `src/app/layout/Portofolio.js:427-456` closes on Escape but has no dialog semantics or focus trap, allowing Tab to reach the page behind the overlay.

5. **HIGH — R-39: Continuous motion has no pause control.** `src/app/components/AmbientWallpaper.js:6-19` and `src/app/globals.css:172-185,248-256,269-277,839-847` run multiple ambient and orbit animations for 23–38 seconds or indefinitely. Reduced-motion preferences are respected, but visitors who have not enabled that system preference cannot pause the motion.

6. **HIGH — R-39: Several touch targets are below 44 × 44 px and lack complete control states.** `src/app/components/Navbar.js` styles desktop links at 42 px and mobile menu controls at 38 px (`src/app/globals.css:382-390,472-480`); project filter buttons use small text with `py-2` (`src/app/layout/Portofolio.js:348-360`). Several buttons also lack an explicit pointer cursor and active state.

7. **HIGH — R-02: Visible copy contains em dashes.** Examples include project names and summaries in `src/app/layout/Portofolio.js:14-15,83` and employment dates and descriptions in `src/app/layout/Experience.js:12-18,40-48,63-74`. The core rule treats these as a hard gate.

8. **HIGH — R-37: No design direction or liveliness dials are recorded.** There is no `DESIGN.md` in the repo, and the site does not declare ENERGY, RHYTHM, or MOTION. The current UI is not identified as a “draft without direction.”

9. **HIGH — security risk outside the antislop rule set: Blog HTML is rendered without sanitization.** `src/app/blog/[id]/page.js:95-98` inserts `post.content` from an API directly through `dangerouslySetInnerHTML`. If that API content can contain untrusted markup, it can execute hostile HTML or scripts in visitors’ browsers.

10. **MEDIUM — R-01, R-07, R-10, R-13, R-31: The visual effects form an undocumented stack.** `src/app/globals.css:162-194,313-340,527-537` combines blurred red and blue glows, a grid, backdrop blur, shadows, and animated light streams. The hero adds an orbital graphic and more glow at `src/app/layout/Home.js:124-133`. No design brief records the purpose for this combination.

11. **MEDIUM — R-39: Contact form status changes are not announced to assistive technology.** `src/app/layout/Contact.js:64-67` renders success and error text without a live region or status role, so a screen reader may not announce the result after submission.

12. **LOW — R-14: The About capabilities use three identical cards.** `src/app/layout/About.js:52-63` gives Web products, Systems, and Infrastructure the same card size and treatment without indicating why they have equal visual weight.

13. **LOW — Code-comment checklist: Comments narrate visible markup.** `src/app/layout/Home.js:69-75` labels a frame, accent detail, and image wrapper immediately before those elements. Those comments repeat what the markup already shows.

## Audit limits

- This was a source and asset audit. The local Next.js server could not start because the sandbox denied binding to `127.0.0.1:3000` (`EPERM`), so no browser click-through, rendered breakpoint inspection, or live API check was possible.
- No product files were changed. Per after mode, fixes should wait until the owner selects finding numbers.
